# MINCOFFE — FINAL AESTHETIC VERSION

Website coffee shop premium dengan 10 slide utama.

## Isi
- 30 menu coffee, termasuk Butterscotch
- 20 makanan berat
- Foto menu memakai foto nyata HD dari Unsplash, bukan AI
- Nomor telepon: 081111806724
- Background dark espresso + cream, daun/coffee-bean decorative feel, typography editorial
- Responsive HP/laptop

## SETTING MENU
Buka `settings.html`.

Di halaman Setting kamu bisa:
1. Mengubah nama coffee shop.
2. Mengubah nomor telepon.
3. Mengubah alamat dan jam buka.
4. Mengubah nama setiap menu.
5. Mengubah harga setiap menu.
6. Mengubah URL foto HD.
7. Upload foto sendiri dari HP/laptop.

Perubahan disimpan memakai localStorage browser. Jadi kalau dipakai di GitHub Pages, setting tersimpan pada browser/perangkat yang melakukan perubahan; localStorage tidak mengubah file GitHub.

## GitHub
Upload `index.html`, `settings.html`, `style.css`, `settings.css`, `script.js`, `settings.js`, dan `data.js` ke repository yang sama.
